# plugins/post-fx

Additional Post-Processing filters (custom LUTs, branded intros/outros,
platform-specific auto-crop rules, ...) that plug into
`services/post-processing` without modifying its core stitching/upscale/
audio pipeline.

**Status:** empty by design in Phase 0 — `services/post-processing`
itself doesn't exist yet as executable code (Phase 5 target).
